# Doubao

Your browser is Doubao's built-in browser Skill or tool, the one that shows pages in the side browser beside the chat; it can open the editor's local page. On macOS it is the `browser-use-automation-mac` Skill; on Windows, `browser-use-automation`. If neither is there, use whichever Skill or tool now drives the side browser. A user asking to see their resume is asking for a page to be shown. When it cannot open the page, hand the `url` over with `present_files`; opening it in the system's default browser puts it outside Doubao.
